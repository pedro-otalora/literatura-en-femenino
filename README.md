# Literatura en femenino

Sitio web de unas jornadas y un concurso literario ficticios sobre la literatura escrita por mujeres. PEC2 de Herramientas HTML y CSS II del Máster en Desarrollo de Aplicaciones y Sitios Web de la UOC.

- **Producción:** [pendiente]
- **Autor:** Pedro Otálora Giménez

## Tecnologías

UOC Boilerplate 3.14.0 (Parcel 2 y Sass), Bootstrap 5.3 personalizado con Sass, BEM + ITCSS, Stylelint, Typed.js y Bootstrap Icons.

## Uso

```bash
npm install      # instalar dependencias
npm run dev      # servidor local en http://localhost:8123
npm run build    # Stylelint y versión de producción en dist/
```
